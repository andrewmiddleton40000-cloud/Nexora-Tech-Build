# NEXORA TECHNOLOGIES — WEBSITE BUILD PROMPT

Build a premium, modern, production-ready corporate website for a technology company called **Nexora Technologies**.

## BRAND

**Company:** Nexora Technologies

**Tagline:**
Digital Solutions. Built for Growth.

**Positioning:**
Nexora Technologies is a digital technology consultancy that helps businesses, entrepreneurs, professionals, and organizations transform ideas into modern digital solutions.

Nexora provides technology solutions including websites, web applications, mobile applications, e-commerce platforms, business systems, AI solutions, automation, integrations, hosting, and ongoing technical support.

The brand must feel like a **premium technology consultancy**, NOT a cheap freelance web-design company.

---

# VISUAL IDENTITY

Use the following brand direction consistently.

### Primary colors

* Midnight Navy: #0B1020
* Electric Blue: #155EEF
* Cyan: #22D3EE
* Slate Gray: #94A3B8
* White: #FFFFFF

### Typography

Use:

* Sora for headings and major branding
* Inter for body text, UI elements, forms, and supporting content

If those fonts cannot be loaded directly, use close modern geometric sans-serif alternatives.

### Logo

Use the Nexora N monogram as the primary brand symbol.

The logo is a modern geometric/ribbon-style "N" using blue-to-cyan technology colors.

The website should support:

1. Full Nexora Technologies logo
2. Icon-only N logo
3. Light-background version
4. Dark-background version

Do not create a generic technology logo. The existing Nexora N monogram should be treated as the official brand mark.

If a logo asset is supplied later, make it easy to replace the temporary logo with the supplied asset without restructuring the website.

---

# DESIGN DIRECTION

Create a high-end, minimalist technology aesthetic.

Think:

* premium technology consultancy
* modern SaaS company
* sophisticated corporate website
* dark navy backgrounds
* controlled blue/cyan accents
* subtle gradients
* clean typography
* generous whitespace
* sophisticated cards
* subtle animations
* professional layouts

Avoid:

* cheesy stock imagery
* excessive neon effects
* excessive glowing elements
* cartoon graphics
* generic IT company designs
* excessive rounded cards
* clutter
* cheap-looking gradients
* excessive animations

The site should look credible enough for a business owner considering a major technology project.
